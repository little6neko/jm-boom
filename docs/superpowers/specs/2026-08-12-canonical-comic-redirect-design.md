# 主漫画规范 ID 与详情自动跳转设计

日期：2026-08-12
状态：待实现前终审

## 1. 背景与证据

上游 `/album` 接口允许使用连载章节 ID 查询详情。以章节 `1459963` 为例，响应会把它作为独立详情返回，但它实际属于主漫画 `1423951`。直接解密同一次上游原始响应后确认：

- 请求章节 `1459963`：`id = 1459963`，`series_id = 1423951`。
- 请求主漫画 `1423951`：`id = 1423951`，`series_id = 1423951`。
- 两次响应包含相同的 26 项 `series`，但不需要依靠 `series[0]` 推断主漫画。

当前 `ComicDetailPayload` 未声明 `series_id`，Serde 会忽略该字段，因此本地 API 和前端暂时无法识别规范主漫画 ID。

## 2. 目标与范围

任何方式进入 `/comic/:comicId` 详情页时，只要上游明确指出另一个主漫画 ID，就以 `replace` 导航到主漫画详情，包括：

- 搜索、推荐、排行、收藏等卡片入口。
- 浏览器手动输入或外部链接。
- 后续新增但仍指向统一详情路由的入口。

Reader 的 `/reader/:comicId` 是章节阅读地址，不做主漫画跳转。详情页章节按钮仍直接进入 Reader。

## 3. 后端数据模型

### 3.1 上游解析

`ComicDetailPayload` 增加 `series_id`：

- 兼容上游返回字符串或数字。
- 字段缺失、`null` 或其他无法转换的值时解析为空字符串。

### 3.2 规范 ID

领域层 `ComicDetail` 增加 `canonical_id`。规范规则为：

1. `series_id` 去除首尾空白后是非零纯数字 ID，则使用它。
2. 否则回退为响应自身 `id`。

不使用 `series[0].id` 作为备用推断，避免章节排序或异常响应导致误跳转。

详情 DTO 增加 `canonicalId`，其他现有字段和接口路径保持不变。

## 4. 前端跳转

前端 `ComicDetail` 和 API 映射增加 `canonicalId`。若前端热更新时仍连接尚未重启的旧后端，API 映射会把缺失的 `canonicalId` 回退为响应自身 `id`。详情查询成功后调用一个独立的纯函数判断跳转：

- `canonicalId` 是非零纯数字，且与当前路由 `comicId` 不同：返回目标 ID。
- 字段缺失、非法或与当前 ID 相同：不跳转。

`ComicDetailPage` 在 effect 中使用 `replace: true` 导航到同一路由的规范 ID。等待导航时继续显示现有详情骨架，不挂载 `ComicDetailView`，因此用户不会对章节别名执行收藏、下载或阅读操作，也不会短暂看到错误详情。主漫画响应的 `canonicalId` 等于自身，跳转在下一页终止。

首次访问章节别名需要先获取一次别名详情以读取 `canonicalId`，随后获取主漫画详情。现有 React Query 缓存保留别名响应，使重复入口可以更快完成判定；本轮不增加独立映射缓存或数据库表。

## 5. 错误处理

- 别名详情请求失败：沿用现有详情错误页和重试按钮，不猜测主漫画。
- 主漫画详情请求失败：跳转后的主漫画页面沿用同一错误处理。
- `series_id` 缺失、为 `0`、为空或非数字：留在当前详情页。
- 自指向 `series_id`：正常渲染，不发生导航。

## 6. 测试与验证

后端测试覆盖：

- `series_id` 为字符串和数字时均能解析。
- 缺失、`null`、`0` 和非法值回退到响应自身 ID。
- 详情 API 使用 camelCase 输出 `canonicalId`，现有字段契约不变。

前端测试覆盖：

- 章节 ID 与规范 ID 不同时返回跳转目标。
- 自指向、缺失、`0` 和非法规范 ID 不跳转。
- API 映射保留 `canonicalId`。

实现提交前运行后端全量测试、Rust 格式与 Clippy，以及前端全量测试、触及文件格式检查、Lint 和生产构建。重启 tmux 后端后，实际请求 `1459963` 应返回 `canonicalId: "1423951"`，通过 `5173` 打开 `/comic/1459963` 应替换为 `/comic/1423951`。

## 7. 提交边界

设计文档单独提交。功能代码形成一个独立提交，包含上游字段解析、领域及 DTO 契约、前端映射和详情路由跳转，不修改 Reader、收藏数据或阅读历史。除非用户另行要求，不推送远端。

## 8. 验收标准

- `/comic/1459963` 自动替换为 `/comic/1423951`，返回按钮不会再次落入别名页面。
- `/comic/1423951` 正常展示且不重复导航。
- 所有指向统一详情路由的入口自动获得相同行为，无需逐个修改链接。
- 非连载、缺失或异常 `series_id` 的详情保持现有行为。
- Reader 章节阅读不受影响。
