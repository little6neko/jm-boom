# 章节卡片副标题一致性设计

日期：2026-08-12
状态：待实现前终审

## 1. 背景

漫画详情页目前只在上游提供原始章节名时显示灰色的 `第X话` 副标题。没有原始章节名时，主标题会回退为 `第X话`，但副标题整行不渲染，导致这些章节卡片比带原始标题的卡片更矮。

## 2. 展示规则

详情页多章列表始终显示灰色话数副标题：

- 有原始章节名：主标题保留原标题，副标题显示灰色 `第X话`。
- 无原始章节名：主标题显示 `第X话`，副标题也显示灰色 `第X话`，允许上下两行重复。
- 话数继续优先使用 `sort`，缺失时使用现有的稳定正序位置。

始终渲染同样的两行结构，使卡片高度和内容区域布局保持一致，不额外设置固定像素高度。

## 3. 保持不变

- “章节”标题和现有正逆序按钮不变。
- 无章节数组的单章卡片继续显示“单章 / 单行本”。
- 已读灰色卡片状态、浅色和深色主题、徽标及链接行为不变。
- Reader、下载列表、阅读历史和继续阅读按钮不调整。

## 4. 实现与验证

仅修改详情页章节卡片，取消 `episodeLabel` 的条件渲染并始终显示该副标题。现有章节展示测试继续覆盖原标题、回退标题和稳定话数；提交前运行前端测试、定向格式检查、Lint 和生产构建。

本次修正形成独立提交，不改写已有的第 3、5、6 项提交。

## 5. 验收标准

- 带原标题的章节显示“原标题 / 灰色第X话”。
- 不带原标题的章节显示“第X话 / 灰色第X话”。
- 两类章节卡片高度一致。
- 单章、排序、已读状态及其他页面行为没有变化。
